For each i ∈ {0, 1, 2}:   train R̂H on (ot−i, Ht · wi)

RLHF — Reinforcement Learning from Human Feedback

Bradley-Terry Preference Model

Instead of per-timestep scalar feedback (TAMER), RLHF learns from pairwise trajectory preferences:

P[σ¹ ≻ σ²] = exp(Σ r̂(o¹)) / (exp(Σ r̂(o¹)) + exp(Σ r̂(o²)))

A neural network reward model r̂ is trained via cross-entropy loss on human preference labels.

Ensemble Improvements (K=3)

  • 3 independent reward predictors on bootstrapped subsets
  • Uncertainty filtering: high-variance pairs skipped
  • Reward normalisation via Welford's online algorithm
  • 500-step Gymnasium cap (vs 200 for TAMER)

RLHF Pipeline

Collect trajectory pairs → Oracle labels preference → Train reward ensemble → Agent trains with r̂ens + renv

Also tested: RLHF Single (1 model, no ensemble) — failed due to ~1.2 labels/episode (insufficient data).

3 Exponential > Uniform Credit

Exponential gives 23% more weight to the most recent (most causally relevant) observation:

Result: more accurate reward model → HCRL achieves 12.8% ≥195 with consistent late-phase compounding across all 3 seeds.

Key Takeaways

1. Credit assignment is the most impactful innovation
Both CAF methods achieve 9–12.8% ≥195 rates — 11–16× the baseline. The 3× data expansion creates a compounding virtuous cycle.
2. VI-TAMER works but requires seed selection
Reversed from 0% → 9.0% ≥195. TD propagation amplifies both good and bad initialisations.
3. Exponential credit outperforms uniform for HCRL
41% weight on most recent observation aligns magnitude with causal relevance.
4. Late timing = best simple strategy
Highest avg last-20 (151.3), lowest variance (std=11.7). No credit infrastructure needed.
5. Staleness framework explains timing paradox
A stale model harms performance only if it is strong enough to override environment signals.

Limitations & Future Work

Combined timing + credit assignment
Late-window oracle feedback + exponential credit expansion — not yet tested together.
VI-TAMER variance reduction
Ensemble VI-TAMER: average multiple reward models to reduce initialisation sensitivity.
Exponential credit for VI-TAMER
Currently uses uniform. Exponential may reduce TD magnitude dilution.
Credit window tuning
Compare W ∈ {1, 2, 3, 5} with exponential credit for both HCRL and VI-TAMER.
RLHF scaling study
200 → 500 → 1,000 episodes: identify minimum preference dataset for convergence.
